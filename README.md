## 快速开始

直接在浏览器中打开 `index.html`，通过章节卡片导航到各章内容。

每章为 1920×1080 固定尺寸的幻灯片，页面会自动缩放适配屏幕。底栏提供翻页按钮和页码显示。

## 编辑内容

有两种编辑方式：

1. **直接编辑 HTML** — 每个章节文件包含所有内容和样式，可直接修改
2. **浏览器内编辑** — 点击页面左上角（80×80px 透明区域），然后点击出现的"编辑"按钮，即可直接在页面上修改文字内容

## 项目结构

```
index.html              — 课件目录 / 主页
第N章_*.html            — 各章幻灯片
images/                 — 示意图、显微组织图等图片资源（~350 张 JPG）
README.md
CLAUDE.md
```

每章为一个独立的 HTML 文件，所有样式内联在文件中，不依赖外部资源（除 Google Fonts 和 KaTeX 数学公式库外）。

## 技术特点

- 纯静态页面，无需构建或服务端支持
- CSS 网格布局（两栏/三栏）展示对比内容
- KaTeX 渲染数学公式
- 响应式缩放适配不同屏幕
- 支持打印（每页幻灯为一页）
- 内置 contenteditable 编辑模式
- 章内可替换主题色（参考 `第7章_铸造_blue.html`）
